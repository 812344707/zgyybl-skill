# zgyybl-skill

骨科病历审查与书写技能。当前版本：**0.29.1**。

用于审查学生病历，以及根据诊断、术式、实际资料和同一病例上下文书写骨科住院文书。审查与写作共用事实边界，详细规则按需读取。

## 功能

- **审查**：病历规范、诊疗逻辑、前后一致性、医疗纠纷风险；保留原文并提供定位和修改建议。
- **写作**：诊断导向专科检查、中医首次病程、围手术期、阶段小结、转科出院、讨论、抢救死亡及告知文书，统一目录覆盖20类文书。
- **完整与局部**：先确定所选范围，再选择实际整理、通用拟稿、示例或只列结构；实际资料不自动触发全文，明确完整请求使用完整骨架或适用模板。
- **严格填空**：仅替换获准的[]占位符，括号外逐字保留。
- **参照学习**：根据用户提供的照片、范文和反馈，维护去除个案信息的通用规则。

## 使用

将包含`SKILL.md`的仓库目录作为`zgyybl-skill`放入所用工具的技能目录。Codex用户可使用`~/.codex/skills/zgyybl-skill/`，或对应的自定义技能目录。

显式调用：

```text
用 $zgyybl-skill 审查学生入院记录，定位问题并提出修改建议：……

用 $zgyybl-skill 写一个右股骨颈骨折的专科检查示例，我再按患者情况修改。

用 $zgyybl-skill 按以下实际资料，只整理术前小结的术者术前查看患者情况：……

用 $zgyybl-skill 列出完整术后首次病程结构，保留空白重点提醒供我标注。

用 $zgyybl-skill 只补下面原文的[]，其他文字不改，只输出纯文本：……
```

实际病史、体征、检查、时间、查看、讨论、治疗执行及签署按本例已有资料处理。示例保持示例身份，未知或冲突按对应模式处理。生成文本属于审查意见或书写草稿，不表示已完成正式质控、签署或归档。
