# zgyybl-skill

**面向骨科住院场景的病历审查与书写 Skill。** 当前技能版本：**0.30.0**。

适合带教医师审查学生病历，也适合临床医师按诊断、术式和病例资料起草文书。你可以要求写一栏、指定几项、列出完整结构，或整理完整文书。

本项目是供 AI 工具读取的指令与模板包，主要使用环境为 Codex；需先具备可用的 AI 工具环境。图片识读和联网查证取决于所用工具的能力与权限。

[快速上手](#快速上手) · [功能](#功能) · [安装方法](#安装方法) · [使用示例](#使用示例) · [更新方法](#更新方法) · [常见问题](#常见问题)

## 快速上手

### 1. 让 Codex 安装

在 Codex 中复制以下内容：

```text
用 $skill-installer 从 https://github.com/812344707/zgyybl-skill 安装技能。
SKILL.md 位于仓库根目录，仓库内路径为 .，安装名称为 zgyybl-skill。
```

### 2. 试用一次

安装完成后，在下一条消息输入：

```text
用 $zgyybl-skill 列出完整术前小结的结构，每项保留内容说明和空白“重点提醒”，方便我标注。
```

### 3. 说清本次范围

例如“只审查现病史”“只写术前小结四项”“写完整术后首次病程”或“仅补[]，其他文字不动”。完整与局部、实际资料与示例模式分别判断，详见下方示例。

## 功能

| 功能 | 适合的任务 | 交付内容 |
| --- | --- | --- |
| 病历审查 | 学生病历、指定片段或多份同病例记录 | 从病历规范、诊疗逻辑、前后一致性、医疗纠纷风险四方面定位问题并提出修改建议 |
| 通用规范写作 | 已知诊断、术式或中医诊断与证型 | 所选栏目中的通用医学意见、鉴别思路和拟行原则 |
| 诊断导向示例 | 先生成专科检查范文，再按患者情况修改 | 有明确示例身份的可编辑模板 |
| 实际资料整理 | 已有病史、查体、报告、医师意见或治疗经过 | 保留事实、来源、时间、侧别和行为状态的临床段落 |
| 遗漏与不足提醒 | 写作后发现影响本次记录的缺项、冲突或表述依据不足 | 在正文尾部另列简短提醒，指出具体项目和补充或核对方向 |
| 严格[]补全 | 原文只能修改占位符 | 仅填指定槽位，括号外逐字保留，纯文本输出 |
| 照片与反馈学习 | 学习用户指定的范文、照片或修改意见 | 将去除个案信息的结构、措辞和适用条件更新到本地技能规则 |

### 覆盖哪些文书

- **入院与首次病程**：学生入院记录审查、诊断导向专科检查、常规首次病程、中医首次病程。
- **围手术期**：术前小结、术前讨论、手术记录、普通术后首次病程及术后转入重症监护病房（ICU）版本。
- **阶段与交接**：阶段小结、转出、转入、出院记录。
- **沟通与告知**：手术知情同意、治疗方法选择、住院期间医患沟通、拒绝检查或治疗、病危通知。
- **特殊记录**：抢救、死亡、24小时内入院死亡、疑难病例讨论等。

原模板的20类文书及默认栏目以[写作目录](references/writing-workflow.md#骨科住院文书)为准，其他已有文书按本次请求使用。默认局部范围中，术前小结为四项、普通术后首次为三项、ICU版为四项、出院记录为三项；明确要求完整文书时按对应完整骨架、所给院内模板或适用依据展开。

## 安装方法

### 方式一：通过 Skill Installer 安装（推荐）

使用上方[快速上手](#快速上手)中的安装提示词即可。这个仓库的`SKILL.md`在根目录，安装时选择仓库内路径`.`，并明确名称`zgyybl-skill`。

供安装器识别的参数为：

```text
--repo 812344707/zgyybl-skill --path . --name zgyybl-skill
```

安装器会按当前环境选择目标技能目录。若已存在同名技能，应先处理已有副本，再决定更新或合并；无需重复安装第二份。

### 方式二：通过 Git 手动安装

需要已安装 Git。以下命令使用当前官方文档中的用户级目录`~/.agents/skills/`。若你的既有环境明确使用`~/.codex/skills/`或其他自定义目录，请将目标路径改为该目录，并保持同名技能只有一份。目录依据见[OpenAI 官方技能文档](https://learn.chatgpt.com/docs/build-skills#where-codex-loads-local-skills)。

**macOS / Linux / WSL：**

```bash
mkdir -p "$HOME/.agents/skills"
git clone https://github.com/812344707/zgyybl-skill.git "$HOME/.agents/skills/zgyybl-skill"
```

**Windows PowerShell：**

```powershell
New-Item -ItemType Directory -Force -Path "$env:USERPROFILE\.agents\skills" | Out-Null
git clone https://github.com/812344707/zgyybl-skill.git "$env:USERPROFILE\.agents\skills\zgyybl-skill"
```

在 WSL 内运行 Codex 时使用上面的 Linux 命令，将技能放在 WSL 的用户目录中。

### 方式三：下载 ZIP

1. 在[仓库首页](https://github.com/812344707/zgyybl-skill)点击 **Code → Download ZIP**。
2. 解压后，将包含`SKILL.md`的文件夹重命名为`zgyybl-skill`。
3. 将整个文件夹放入所用工具的技能目录，保留`references/`、`scripts/`、`agents/`和`tests/`。

正确层级如下，避免多套一层同名目录：

```text
技能目录/
└── zgyybl-skill/
    ├── SKILL.md
    ├── README.md
    ├── agents/
    ├── references/
    ├── scripts/
    └── tests/
```

安装完成后用`$zgyybl-skill`发起任务。Codex支持自动发现技能；若未出现，先确认安装目录和文件层级，再尝试重启。安装与发现方式参考[官方说明](https://learn.chatgpt.com/docs/build-skills#install-curated-skills-for-local-use)。

## 使用示例

以下病例内容均为虚构示例。复制提示词后，按实际任务替换文书类型和资料。

### 1. 审查学生入院记录

```text
用 $zgyybl-skill 只审查下面学生入院记录的现病史与辅助检查，定位原句并给出修改建议，保留原文：

现病史：患者跌倒后右髋疼痛、活动受限3小时入院。
辅助检查：虚构甲院X线报告左股骨颈骨折。

请重点核对前后一致性，不推断未提供的其他章节缺失。
```

### 2. 生成可修改的专科检查示例

```text
用 $zgyybl-skill 写一个右股骨颈骨折的专科检查示例，我再按患者实际情况修改。采用规范医学术语，只输出可复制的正文。
```

这里请求的是示例；生成的示范体征不代表已经为患者完成检查。

### 3. 中医首次病程的通用写作

```text
用 $zgyybl-skill 书写中医首次病程的以下栏目：中医辨病辨证依据、中医鉴别诊断、西医鉴别诊断，以及检查评估、中医治疗、西医治疗、中医调护与康复四项计划。

中医诊断：骨折病。
证型：气滞血瘀证。
西医诊断：右股骨颈骨折。
主症：右髋疼痛、活动受限。

采用通用、概括、规范的写法，不补造舌脉、检查结果或已执行治疗；只输出所选正文。
```

如果还需要“西医诊断依据”，在请求中明确加上该项。

### 4. 术前小结四项

```text
用 $zgyybl-skill 通用规范地写术前小结的手术指征、注意事项、术者术前查看患者情况、术前讨论结果四项。

诊断：右股骨颈骨折。
拟行：右侧全髋关节置换术。

未提供患者术前状态、实际查看及讨论完成情况。通用医学意见可草拟，实际情况按缺项规则处理，不扩展成全文。
```

### 5. 只整理实际资料中的一栏

```text
用 $zgyybl-skill 仅整理术前小结的“术者术前查看患者情况”一栏，不增加其他栏目。

本例已给资料：患者神志清楚，精神尚可；心内科会诊建议进一步评估心功能。没有提供术者实际查看记录，也没有手术禁忌证评估结论。

仅使用这些资料，输出纯文本。
```

“实际资料”决定事实来源，不会自动把单栏请求扩展成完整文书。

### 6. 完整文书或完整结构

先列完整结构供标注：

```text
用 $zgyybl-skill 列出完整术后首次病程记录结构。每项包含栏目标题、内容说明及空白“重点提醒”；只列结构，不写病例模拟。
```

按实际资料写完整记录：

```text
用 $zgyybl-skill 只按以下资料整理完整实际术后首次病程，未知项目保留必要缺项。

手术日期：2026-10-22，14:30术毕；实际记录时间未提供。
已行右侧全髋关节置换术。
医师记录术中诊断：右股骨颈骨折。
术毕血压：110/70 mmHg。
医师已定计划：观察疼痛及患肢情况。
其他资料未提供，不推定麻醉、人员、手术细节或恢复结果。
```

完整请求会展开相应栏目，但不会因此补造未知事实。需要完整示例时，请明确写“完整示例”，并给出允许采用的模拟前提。

### 7. 仅补[]，其他文字不改

```text
用 $zgyybl-skill 只补下面原文的[]，保留方括号，括号外逐字不改，只输出纯文本。

原文：血压[]mmHg；过敏史[]。
资料：血压120/80 mmHg，过敏史未提供。
```

此例预期补全为：

```text
血压[120/80]mmHg；过敏史[待补充]。
```

数字单位的常规格式调整不会修改本例被冻结的括号外文字。若需要去掉占位符括号，应在请求中明确说明。

### 8. 学习照片、范文和修改意见

```text
用 $zgyybl-skill 学习我提供的范文和修改意见，将通用的结构、措辞及适用条件更新到对应本地规则，保留其他文书能力。只保存去除个案信息后的规则，不保存患者身份、原始照片或整份病例转录。
```

这是本地技能规则迭代，不是模型训练；更新本地规则也不会自动提交到GitHub。若只希望照片用于本例成稿，请写“仅用于本次病例，不更新技能”。

### 常用输出要求

可在上述请求末尾补充：“只输出纯文本”“保留院内标题与编号”“只写某一栏”，或“先审查再修改，只交付修订正文”。只请求审查时保留原文；同时请求修改时才进入对应写作步骤。

### 写作后的尾部提醒

普通写作后如有实质遗漏、前后冲突或依据不足，会在末尾单列“遗漏与不足提醒（非病历正文）”。提醒只针对本次范围，通常合并为1—3项并说明补充或核对方向，便于修改；正文的必要缺项仍保留，不把“未提供”写成“未检查、未做”。

通用拟稿、示例和空白结构不会因缺少未要求的患者细节而附整套采集清单。只要求纯文本时，提醒也用纯文本并另起一段；本次明确要求“只要正文、不附说明”或严格[]补全时不自动追加普通提醒。当前未处理的重大安全问题仍按专门条件提示。完整规则见[遗漏与不足提醒](references/writing-workflow.md#遗漏与不足提醒)。

## 更新方法

**通过 Git 克隆安装：**先确认工作区状态，再更新。以下以官方用户级目录为例，自定义目录请替换路径。

```bash

git -C "$HOME/.agents/skills/zgyybl-skill" pull --ff-only
```

如果已通过照片或反馈修改本地规则，先备份、提交或合并这些修改，再执行更新，保留自己的写法。

**通过安装器或 ZIP 安装：**这是文件副本，可重新下载最新版后，与原副本比较并合并本地修改；不能假设该目录具备Git更新能力。也可以让Codex协助更新，并明确要求保留本地改动。

## 常见问题

**装好了但找不到技能？** 检查目标目录是否是当前工具实际读取的位置，`SKILL.md`是否直接位于`zgyybl-skill/`下，以及是否已有同名副本或被环境配置禁用。确认后再尝试重启。

**为什么会出现“待补充”？** 实际记录中依赖患者事实的项目未提供时，技能保留必要缺项。需要通用表达或示例时，请明确指定模式；这不会把未知患者状态变成正常结果。

**为什么默认没有写出所有栏目？** 部分文书默认沿用已确认的局部范围。直接写“完整文书”“完整结构”或“完整示例”即可；有院内模板时一并提供。

**能直接用在普通聊天网页里吗？** 普通对话未必会加载仓库文件。请在支持本地Agent Skills及相对引用的工具中安装；单独粘贴`SKILL.md`不等于已经加载所有配套指引。

## 事实与资料边界

实际病史、体征、检查、时间、查看、讨论、治疗执行和签署均按本例已有资料整理；示例保持示例身份，未知与冲突就地处理。请优先使用病例代号和去标识化资料。

本技能交付审查意见和书写草稿，不表示已经完成正式质控、签署或归档。保存患者文件、写入电子病历系统、上传或发送仍按本次授权和所用工具的访问权限执行。
