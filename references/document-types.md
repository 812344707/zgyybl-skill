# 文书结构

只读取本次文书对应条目。通用拟稿、示例与实际资料整理按[写作路径](writing-workflow.md#确定书写范围)分别处理；以下局部范围优先，完整骨架用于明确要求全文的场景。空白骨架不证明患者否认或检查正常。院内模板可调整标题和顺序；本次未请求的其他文书不默认扩展。

## 入院记录

建议顺序：一般情况 → 主诉 → 现病史 → 既往史及入院前用药 → 个人史 → 婚育史／适用的月经史 → 家族史 → 体格检查 → 专科情况 → 辅助检查 → 初步诊断 → 医师核签。

- 一般情况按已提供项目整理；入院时间、记录时间、病史陈述者单独核对。
- 主诉保留部位、主要症状及时间；本次起病、变化、诊疗过程按时间顺序写入现病史。“反复5年，加重1周”保留两个时间层次。
- 既往史保留已知疾病、手术外伤、输血、过敏、传染病等信息及入院前实际用药。无资料的类别标待补充，不代写否认。
- 全身体检与专科查体分别组织；只有“生命体征平稳”时可保留该汇总描述，不能扩展出体温、心肺腹或神经检查结果。
- 检查保留日期、机构（若提供）、部位、侧别及关键结果。影像原文与临床诊断分别表述。
- 初步诊断按医生已给结论及主次顺序整理；未给结论时留待医师确认。
- 再次或多次入院时，先概括有资料支持的历次相关住院经过，再写本次情况；历史手术不自动算作本次手术。

## 首次病程记录

中医首次病程局部补写先执行[专门写法](write-tcm-first-course.md)；以下骨架和事实要求用于常规实际记录。

建议顺序：记录时间 → 病例特点 → 拟诊讨论（初步诊断、诊断依据及鉴别）→ 诊疗计划 → 医师核签。

- 病例特点提炼主要病史和已采集的关键阳性／阴性发现，不逐段复制整份入院记录。
- 已有诊断依据按本例事实组织，证据不足应说明不足。鉴别按[拟诊讨论写法](write-first-course.md#拟诊讨论)区分已有医师分析与授权拟稿，放入本次所选栏目。
- 诊疗计划按[计划写法](write-first-course.md#诊疗计划)区分已定安排与授权拟行草稿，不预定执行结果。
- 未提供的初步诊断留待医师确认；未提供且未授权拟写的鉴别或计划保留具体缺项，不以经验填满。

## 日常病程记录

建议顺序：记录时间 → 当次症状和病情变化 → 当次查体 → 新检查结果及已有临床分析 → 已实施措施与效果 → 医嘱调整及依据 → 后续计划 → 已发生的重要沟通 → 医师核签。

- 以本次增量为主。稳定信息仅在有本次确认时写作当前状态；历史检查可引用并标明日期。
- 同时提供昨日和今日资料时，变化描述以可对照资料为依据；不能仅因今日未提到就写“症状消失”。
- 缺少今日查房资料时给待填草稿，不自动复制昨日查体，不连续编写多日“恢复良好”。
- 治疗效果、伤口、引流、活动与负重依实际记录；“未提供新检查”不等同于“复查正常”。

## 上级医师查房记录

建议顺序：查房时间、医师与职称 → 补充病史和体征 → 检查结果 → 病情与诊断分析 → 查房意见和计划 → 医师核签。

查房医师身份、实际查房行为、意见和决定均来自输入。只给了普通病程时不能据此生成某位上级医师已经查房的事实；身份缺失保留待填。

## 术前小结与术前讨论

术前小结的通用拟稿按 [四项写法](write-preoperative-summary.md) 处理。术前讨论按下方所选八项组织，明确要求完整实际文书时再用完整骨架。

### 术前讨论：所选八项

本用户选择初步诊断、术前准备情况、手术指征、拟行手术名称、拟行手术方案、可能出现的意外及防范措施、会诊人员发言记录、讨论所形成的最终结果八项。默认依次仅输出所选正文，采用通用、概括、规范的医学表达。

诊断及拟施手术按本次输入；术前准备写已给实际完成情况，不补会诊、正常结果或禁忌证排除结论。手术指征、方案、风险及防范可根据诊断、拟施手术和同一病例背景草拟医学意见，具体判断按适用一手依据核对；拟行、备选和实际执行分别表达。

会诊人员发言记录依据实际参加人员和已给意见整理。未给发言时，可提供不归属于任何人的通用讨论意见拟稿，保持拟稿身份；不虚构姓名、职称、逐人发言或赞成意见。末项可草拟综合医学意见与拟行安排；已有实际讨论结论时忠实整理，不把拟稿写成“已讨论一致通过”等完成事实。

### 完整实际记录骨架

以下事实要求用于完整实际记录，不阻断前述已授权的通用医学意见拟稿。

术前小结：简要病情 → 已定术前诊断 → 医生给出的手术指征 → 拟行手术及侧别 → 拟行麻醉 → 术前准备及注意事项 → [术者术前查看患者情况](write-preoperative-summary.md#术者术前查看患者情况) → 医师核签。查看情况及其缺项沿用链接中的规则。

术前讨论：讨论时间及参与者 → 病情汇报 → 已有检查与评估 → 诊断、指征、手术及麻醉方案 → 实际讨论的风险和预案 → 各参与者实际意见 → 讨论结论 → 核签。

- 手术指征、麻醉、风险处置和结论需有医生资料；不能由疾病名自动生成。
- 尚未讨论时输出“术前讨论准备稿”或提纲，保留待填写参与意见；不把拟讨论写成已经讨论。
- 未提供禁忌证评估、告知或签署事实时，不写“无手术禁忌证”“已充分告知并同意”“签字齐全”。
- 专门的手术级别及多学科讨论要求需按当前规则和本院制度核实，不能凭术式自行指定。

## 手术记录

建议顺序：患者代号与时间 → 术前诊断 → 术中诊断 → 手术名称、侧别与麻醉 → 术者及助手 → 实际手术经过与术中所见 → 实际失血、输血、标本、植入物和引流情况 → 结束情况 → 医师核签。

- 先由本次实际手术资料串成经过；通用手术步骤仅能用于核对缺项。
- 只有术式名时提供待填骨架，不能生成切口、入路、复位、截骨、固定、假体型号、清点结果、失血量或“过程顺利”。
- 术中诊断按已给的术中结论整理；另有术后诊断时保留其来源和确认时点，不与术中结论相互替代。术前计划或后来报告不能推造术中诊断及效果；手术日期和已给起止时刻如实保留。

## 术后首次病程记录

普通术后三项或转入ICU四项局部写作，先执行 [术后通用写法](write-postoperative-first-course.md)；明确模拟的通用范文与实际记录整理分别处理。以下为完整实际文书的骨架，不要求局部写作展开全部字段。

建议顺序：记录时间 → 实际手术时间、术中诊断、手术名称、麻醉方式和人员 → 手术简要经过及术中情况 → 当前术后状态 → 医生已定的术后处理 → 重点观察事项 → 医师核签。

区分术中事实、术后当时状态和后续计划。用户未给的抗菌、抗凝、镇痛、负重或康复安排保持待确认，不能直接形成个体化医嘱。

## 阶段小结

用户已选定入院情况、入院诊断、诊疗经过、目前情况、目前诊断及诊疗计划六项，按 [阶段小结写法](write-stage-summary.md) 处理。明确模拟时生成通用规范范文；实际记录依据本阶段资料汇总，区分已发生的经过、目前状态与后续安排。完整文书的其他字段仅在另有要求时展开。

## 转出记录

用户已选定入院情况、入院诊断、诊疗经过、目前情况、目前诊断、转科目的及注意事项六项，按 [转出记录写法](write-transfer-out.md) 处理。实际记录概括本科诊疗及转出时情况，拟转、已转与交接完成分别依资料；局部模拟不自动展开转入记录或完整转科手续。

## 转入记录

用户所选六项为入院情况、入院诊断、诊疗经过、目前情况、目前诊断、转入诊疗计划。诊疗经过概括转入前的相关诊疗，目前情况和诊断对应转入时点，计划说明本科接续的检查、治疗、观察与康复安排。

按这六项采用通用规范表述；前五项的组织可参考[阶段小结写法](write-stage-summary.md#六项写法)，并对齐转入前经过及转入时点。转入诊疗计划概括本科接续诊治的目标与拟行原则。实际转入、查体、诊断调整和执行状态依本次资料，明确模拟时保持示例身份，不虚构接收、交接完成或恢复结果。

## 抢救记录

用户确认四项结构为病情变化情况、抢救时间及措施、参加抢救人员、家属谈话或知情告知。

- 病情变化情况：概括抢救前及抢救过程中的主要变化、症状、体征及相关检查。
- 抢救时间及措施：按实际时间顺序记录抢救起止、重要处置时间、措施及患者反应。
- 参加抢救人员：使用实际参加人员的姓名、职称及已知分工。
- 家属谈话或知情告知：使用实际沟通的时间、对象、内容及对方意见。

本条为所选局部结构，不自动生成抢救事件、用药、时间、人员、患者反应或已告知事实；缺失或冲突按实际成稿规则保留。完整抢救记录、补记时限和其他规范判断按本次请求及适用依据另行核对。

## 手术知情同意书

用户所选七项为术前诊断、手术的益处、其他可替代的手术方案、治疗成功的可能性、术中或术后可能出现的并发症及意外情况、康复过程中可能出现的问题（可能出现的后遗症）、拒绝手术可能产生的后果，按 [七项通用写法](write-surgical-consent.md) 处理。局部拟稿不自动扩展患者签署、代理授权或沟通完成记录。

## 治疗方法选择书

原模板包括初步诊断及方法一、方法二、方法三，每种方法分别写名称、优点和缺点。根据诊断、可选治疗方法及本次目标，生成通用、规范的比较正文；明确给出方案时优先比较这些方案，要求拟定时按适用一手依据选择候选方法。

- 优点说明预期治疗获益、功能目标及相关有利特点；缺点说明重要风险、局限、康复负担或进一步治疗的可能，分别对应具体方法。
- 各方法注明主要适用条件，不从同一病名推定所有方案均适合本例，也不把不同方案的预期结果写成等同。
- 方法数量按用户所给或当次指定处理；不为填满三栏追加重复或不适用的方案。冻结原文或仅补[]时仍遵守原结构和专门补全规则。
- 数字、成功率、费用、住院日及恢复期限须有可靠适用来源，不用无依据的比较词承诺某方案更好、更快或更安全。
- 文本是方案比较拟稿；患者已选择、已拒绝、沟通完成或签署等状态依本例事实，不从生成选择书推定已经完成。

## 出院记录

本用户局部写作仅保留“诊疗经过（治疗措施）、出院情况、出院医嘱”三项，默认依次输出，采用通用、概括、规范的临床段落；只选部分时仅写所选项。按原模板编号排版时，保留所选的五、八、九，不自动加回其他栏目。用户明确要求完整记录时再使用下方完整骨架。

- 诊疗经过（治疗措施）：概括住院期间的重要检查、治疗、手术、病情变化及治疗效果，区分已有经过与后续计划。
- 出院情况：概括出院时的症状、体征、功能状态及尚存问题；具体改善、切口愈合、查体及功能结论依本例资料，通用表述不补造恢复结果。
- 出院医嘱：围绕出院后的治疗、病情观察、活动、康复及复查安排组织拟稿；具体药物、剂量、疗程、活动负重和复查时间依已定方案。用户要求通用医嘱时写适用的原则性安排，不生成无依据处方。

普通成稿仅交付所选正文，不附整套资料回执；实际缺失、冲突及拟出院/已出院状态仍按事实规则处理。

### 完整记录骨架

建议顺序：入院／出院时间 → 入院情况与诊断 → 住院诊疗经过及关键检查 → 出院诊断 → 出院时实际情况 → 已决定的出院用药、活动康复、复查和其他医嘱 → 医师核签。

- 串联已发生的住院事件，不把“拟出院”写成已出院。
- 出院诊断沿用医生提供的最终诊断；改善程度、伤口状态和功能以出院时资料为准。
- 出院药物、剂量、疗程、复查时点、负重及康复安排均按已定方案写；未给时逐项待确认，不生成通用处方。
- 24小时内入出院、日间医疗和死亡相关记录有不同条件与字段，应按用户指定类型、模板及现行依据另行核对。

## 住院期间医患沟通记录单

本用户已选定目前诊断、主要治疗手段、重要检查及结果、目前可能出现的意外风险及并发症、药物使用及其不良反应五项。默认依次只输出所选五项，采用通用、概括、规范的医学说明，不附审查或整套补材料回执。

- 目前诊断：使用已给诊断，保留疑似、待排及确诊的区别。
- 主要治疗手段：区分已实施与拟采取的治疗；原模板中的“手术治疗”不是每例默认事实。
- 重要检查及结果：引用本例相关检查及结果，检查计划和典型表现不冒充检查报告。
- 目前可能出现的意外风险及并发症：围绕病情和治疗说明相关未来风险，已发生的并发症与可能风险分别表达；具体医学判断按适用依据核对。
- 药物使用及其不良反应：依据已给或明确拟用药物，说明用途及主要不良反应、观察重点，实际反应与潜在风险分开。未给具体药物时保持原则性描述，不据病名补造处方或实际用药。

本条草拟医学说明；实际沟通时间、对象、发言、理解、选择、同意或签署均依本例事实，不从生成记录单推定已经沟通完成。用户只要求局部时不扩展整套签署或告知程序。

## 拒绝检查与拒绝治疗文书

依据已给诊断、拟行项目及本次背景，按下方对应四项起草通用、概括、规范的医学说明。项目名称、方法、部位和侧别依输入；益处和拒绝后果结合该项目的目的表达，保留适用条件和不确定性，不承诺疗效、虚构成功率或把可能风险写成必然后果。具体医学判断按适用一手依据核对。

实际结果、实施效果、患者拒绝、沟通时间和对象、理解或签署状态均依本例资料。仅生成所选医学内容，不从文书标题补造拟行项目，也不因原模板名称增写免责、责任认定或患者承担全部后果等条款。

### 拒绝检查风险知情及责任承诺书

默认四项：目前诊断、拟行检查项目名称、施行该项检查的益处、拒绝进行该项检查的风险和可能出现的后果。益处和拒检后果围绕该项检查对诊断、评估及治疗安排的作用组织。

### 拒绝治疗风险知情及责任承诺书

默认四项：目前诊断、拟行治疗项目名称、施行该项治疗的益处、拒绝进行该项治疗的风险和可能出现的后果。益处和拒治后果围绕治疗目的、预期获益、病情及功能影响组织。

## 死亡记录单

本用户所选五项为入院原因、入院情况、入院诊断、诊疗及抢救经过、死亡原因及诊断。默认仅按五项组织通用、概括、规范的文字，不自动展开其他文书或生成病例模拟。

入院原因、入院情况及诊断按入院时点整理；诊疗及抢救经过按本例事件的实际时间顺序串联，区分病情变化、实施措施、反应和结果，注明已提供的死亡时间。不能从死亡结局反推病程、抢救措施或观察结果，也不把其他病例的抢救过程套用为本例事实。
