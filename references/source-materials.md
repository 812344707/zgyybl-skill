# 资料识读、出处与交接

用于本次患者的照片、PDF、报告、多来源核对和待回资料交接；处理后返回用户所选的审查或写作路径。事实与示例准入沿用[技能入口](../SKILL.md#事实准入)。仅按诊断写通用段落或专科示例时，不要求用户提供原件或填写结构化表。

## 先看本次材料

- 只读取与当前患者及所选栏目有关的部分。会话图片直接识读；本地图片用图片查看工具核对。PDF的文本层可辅助提取，扫描页及关键字段需查看实际页面；只有文本转录时说明依据转录，不能声称已核验原图。
- 文书截图与原始影像分开；本流程提取可读报告，不将影像像素自行写成正式检查报告或本例已确认诊断。
- 为本次工作保留可定位出处：附件名及页／段、已给机构、检查或报告日期。文件名日期不替代报告内时间；患者转述、正式报告与医师阅片意见分别对待。
- 某页打不开或部分不清时，仅影响相应字段，先完成其他可读内容；指出需要核对的页或项目，不凭熟悉句式补齐。

## 在工作过程中对齐事实

按已有信息保留下列对应关系，不要求每个字段齐全。完成核对后按所选路径交付；病历成稿与单纯资料整理的形式按[常规输出](writing-workflow.md#常规输出)区分：

| 对应项 | 需保持的内容 |
| --- | --- |
| 归属 | 病例代号、解剖部位、侧别、标本及本次／既往属性 |
| 原文 | 症状、检查项目、数值、小数点、比较符、单位、参考区间、报告标记、否定词及确定程度 |
| 时点 | 采样／检查时间、报告时间、记录时间分别保留；不把报告时间当成采样时间 |
| 出处与状态 | 可定位的原件位置；初步、最终、更正、待回或识别不清等实际状态 |

用这些信息组织正文时，仍区分患者陈述、客观结果、医师判断和诊疗安排；不将整理过程变成新的诊断或执行事实。出处默认用于内部核对及审查定位，病历正文保留所需机构、日期及临床内容；用户要求追溯表时再单列出处，不把内部编号塞入复制正文。

## 不清、差异与冲突

- 数字、单位、药名、侧别或否定词识别不清时，保留可辨内容，对受影响项用具体的“［待核实：来源及项目］”标记。未给参考区间时不套成人常用值；报告已有异常箭头可如实转述，不由箭头生成诊断。严格[]采用其[专门缺项约定](bracket-completion.md)。
- 同名检验的单位、标本、检测方法或参考区间不同时，先分别呈现；未确认可比性前不直接串成升降趋势，不隐式换算或统一原始数值。明确请求换算时另行说明方法并保留原值，不把换算当作临床解释。
- 不同时间的真实变化与同一事实的冲突分开。明确的正式更正或医师方案变更保留前后版本、原因及时间；写早先时点的记录时，不能使用后来才可获得的更正或结果。
- 无法解释的侧别、结果或用药冲突同时定位双方，不以出现次数、报告新旧或模板常用值选定结论。影像报告、患者转述和临床诊断的来源不同，不通过静默改值使其一致。

## 待回结果与交接

仅在本例已出现待回检查、未完成会诊或治疗变更时触发，按本次所写时点处理：

- **审查**：核对已记载事项的当前状态、后续回报及复核安排是否衔接。缺少安排时说明现有材料无法核实，不判定未追踪，也不为每例增加固定检查或强制填写追踪人。
- **写作**：在既有诊疗经过、目前情况、诊疗计划、转科注意事项或出院医嘱中保留相应事项，不增设用户未选的新栏目。待回不写成阴性、已完成或已复核；报告后来回报，按实际回报及处理时点另行归纳。
- **安排与变更**：已给追踪对象、责任方、复核时点及继续／暂停／恢复决定时如实写明；未给的不造姓名、时刻或恢复医嘱。仅整理实际资料时保留已知状态；授权拟写计划时可写后续复核原则，保持拟行语态，不把拟稿写成已落实安排。

识读与核对在当前任务中完成。患者资料的保存、发送和学习仍按[文件边界](../SKILL.md#文件与资料处理)及[参照学习](reference-learning.md)处理；本流程不自动建立患者档案、导出原件或将事实写入技能。
