# 骨科入院写作：专科检查为主

入院写作主要帮助用户生成专科检查，学生入院记录审查仍走 [审查路径](review-workflow.md)。写作有两种资料情境：按主诊断生成完整、可编辑的示例范文；或按已采集的实际查体整理患者记录。按本次请求选择，不混淆示范内容与患者事实。

只要求专科检查时就交付该段；入院写作未进一步限定范围时优先生成专科检查。明确要求主诉、现病史等其他段落或完整入院记录时按其要求处理，全文结构见 [入院记录结构](document-types.md#入院记录)。不额外生成首次病程、术前讨论或知情同意书。

## 用户文档中的入院待写栏目

来源为用户于2026-10-23提供的《病历模板（2015.04.15）》入院部分。该材料列的是本次需要协助书写的局部栏目，不用它替代完整入院记录结构，也不据其未列出的项目认定整份病历缺项。用户要求沿用此局部模板时，按原顺序输出：

```text
主诉：
现病史：
既往史：
入院前用药情况：
个人史：
专科情况：
辅助检查：
```

这七栏沿用已确认的分工：学生入院稿以审查和具体修改建议为主；写作以按主诊断生成专科检查示例为主，其他栏目按实际资料归纳整理。主诉、现病史等按下方 [整理本次入院](#整理本次入院) 处理，用药及检查按 [骨科资料落位](#骨科资料落位) 保留事实；专科示例按 [诊断模板分支](#按主诊断生成示例模板) 生成。空白栏目是模板位置，不代表患者否认、未检查或结果正常。原文件名日期仅作为来源标识，不把其中说明直接当作现行规范。

## 按主诊断生成示例模板

用户说“帮我写个股骨头坏死的专科检查”“按主诊断生成一套专科检查，我再修改”等，是请求示例范文；只有诊断也可直接生成，不先要求提供所有真实检查结果，不默认返回满篇待填字段。

1. **确定示例场景**：读取主诊断、部位、侧别及已给病期／术前术后状态。按这些信息选适合的范文。仅有诊断时可采用一个合理且简短说明的示例场景；侧别可写“患侧”，也可在正文外说明本例以左侧／右侧示范。示例设定不表述为患者分期或实际观察。
2. **选择检查内容**：以视、触、动、量及神经／血运为框架，按主诊断、部位和阶段选用，不把所有特殊试验和相邻部位检查都固定加入每例。骨折、关节病和脊柱等分别调整，不能把髋关节范例直接换病名套用。
3. **写成完整范文**：在明确的示例身份下，可以使用与场景相符的示范性正常／异常描述、活动度、阳性或阴性结果，形成用户可逐项改写的临床段落。严格遵循 [医学术语与临床表达](writing-workflow.md#医学术语与临床表达)，使用准确的解剖定位、检查名称及结果。数字和结果是示例设定，不是对诊断必然体征的推断；不生成患者身份、医师签名、检查执行时间或已归档状态。
4. **处理实际信息**：用户要求以部分真实资料为基础生成模板时，已给事实保持原值、侧别和确定程度，其余示范部分仍属于待核对的示例。若用户明确要求“根据实际查体成稿”“不要补任何体征”，则切换到下方实际资料分支，未知保留缺项。未解决的真实资料冲突不凭模板选值。
5. **检查适用性**：示例中不安排故意诱发新鲜骨折异常活动／骨摩擦感、强行活动等检查。病期和安全性影响所选项目时按本例条件删减；拿不准的特殊试验查适用专业来源，不靠堆砌阳性和阴性使段落显得完整。

可用的选材方向（不是每例必填清单）：

| 主诊断或场景 | 范文重点 |
| --- | --- |
| 股骨头坏死、髋部退变等关节病例 | 局部外观、压痛、功能及适用的活动度，按示例场景选择相关试验和肢端神经血运；早期与明显活动受限场景分开。 |
| 四肢急性骨折／脱位 | 皮肤软组织、伤口、肢体姿势及畸形、局部压痛、远端神经血运、相关邻近部位；活动描述服从安全性，不强列正常角度或骨擦感试验。 |
| 腰椎退变、椎管狭窄等 | 脊柱姿势及局部检查、适用的活动、下肢感觉／肌力／反射及相关神经牵拉等项目，按具体诊断选用；不自动把腰椎模板用于颈髓或急性脊柱损伤。 |
| 已明确的术后或再次入院 | 本次皮肤／瘢痕或切口、局部情况、功能和远端神经血运；只有明确处于术后观察阶段时才选敷料、引流等项目，不从“置换术后多年”虚构仍有切口或引流管。 |

### 股骨头坏死参考范文

以下复用用户提供的完整示例，场景为左侧有症状并活动受限的股骨头坏死，供逐项按实际患者修改。它不是所有病期的统一查体结果，也不要求对每位患者实施其中全部特殊试验。

> 双下肢无畸形，左髋部皮肤完好，未见红肿及破溃，左腹股沟中点深压痛，局部未扪及异常活动及骨擦感，左股骨大转子部叩痛阳性，左下肢纵向叩击痛阴性，左髋关节活动受限，活动度：屈曲90°<=>后伸0°，外旋10°<=>内旋15°，内收5°<=>外展15°，左髋关节托马斯（Thomas）征阳性，骨盆外观无畸形，骨盆挤压试验、分离试验阴性。左膝、左踝及左足各关节无畸形，无压痛，活动无受限，肢体远端感觉、血运、皮肤温度未见明显异常。余肢体检查未见明显异常。

生成同类示例可沿用这种连续段落写法。根据用户指定的侧别、病期和需要替换项目及示例数值，不把这段文字设为每种疾病、每种阶段的固定默认值。

## 模板输出

默认交付一份可复制、可编辑的专科检查范文。正文外用“专科检查示例模板（待按患者情况修改）”等简短标题说明其示例身份；需要选用假设侧别或阶段时一并简短注明。复制正文内不夹解释、链接或逐句免责声明，不强制把每个示范结果换成空白。用户指定院内格式、长度或纯文本时按其要求；纯文本模板仍以简短示例标题与患者实际记录区分。

用户已明确只要示例正文、且上下文已清楚其模板身份时，可仅给示例正文。仅补[]的请求始终以 [冻结原文规则](bracket-completion.md) 为准，不能借诊断模板模式补写括号外内容。普通写作的实质遗漏与不足按[尾部提醒](writing-workflow.md#遗漏与不足提醒)另列，示例未设定的个体细节不自动列为缺项。

## 按实际查体整理

用于“根据以下实际检查整理”“只写已给查体”等患者记录任务。把已有部位、侧别、视触动量及神经血运结果组织成专科段落，保留原数值、确定程度及受限未查的实际说明；未提供不写成正常、阳性或阴性。资料缺失只标具体项目，不要求重交整份入院病史，也不复制上方示例数值。

## 明确要求完整入院记录时

本节及下方内容用于用户明确要求全文或对应病史段落时；仅要专科模板时无需展开。

### 整理本次入院

- **主诉**：从部位侧别、主要症状／体征及时间提炼。“反复数年、加重数周”和受伤后小时数分层保留；不得把已给大致时间擅改成精确起病时刻。病名、拟行术式和本次治疗侧分别核对，不能代替未提供的症状。
- **现病史**：按起病／受伤 → 症状和功能变化 → 已发生的诊疗及效果 → 目前情况和本次入院目的组织。散乱输入可重排；未给因果不写“因治疗失败而入院”，未给入院目的不推定来院手术。
- **既往与本次**：相关疾病、历史手术、外伤、过敏和入院前实际用药放在相应病史；与本次有关的旧诊疗可在现病史简述并标时间。患者口述的外院诊断、药品和术式与已取得的报告／医师结论分别表达。
- **一般状态**：饮食、睡眠、二便、体重等按已给资料写。没有描述不生成“均正常”，也不从疼痛或年龄推断一般状态。

### 骨科资料落位

全身生命体征和系统体检与专科情况分开。仅有汇总描述时保留相同粒度，例如确实给出“生命体征平稳”可以照写，但不能拆成未提供的体温、血压、心肺腹结果。

专科查体按 [骨科提示](orthopedics.md) 整理实际部位的皮肤软组织、压痛、畸形、活动及测量、远端血运与神经等已给内容。骨折分型、肌力、关节活动度和评分必须有数据；某项未给不影响先写其余已知项目，不补整套正常查体。

检查保留日期、机构／来源、部位侧别及关键结果，外院信息不改成本院检查。报告缺机构、时间或单位时只标对应缺项；未取得影像全文时不将摘要扩展为完整报告。诊断按医生已给结论和顺序写，保留初步、待排或已确诊状态。

再次入院先小结有资料的历次相关住院经过，再写本次经过；既往已完成手术与本次拟行手术分开，双侧病变与本次治疗侧分开。

### 缺项与完成核对

可写部分先成稿。整个病史或全身体检类别未给时合并标记，不列满未采集的阴性项；过敏、侧别等关键缺项具体标明。只有全空请求时，采集“本次时间、年龄性别、症状及演变、既往与过敏／用药、实际查体、报告、医生初诊与入院目的”，允许暂缺，不要求重复提交已有资料。

交付前核对：主诉与现病史时间层次相符；本次与历史诊疗分明；症状、查体、检查、诊断和治疗侧有对应；未知内容没有变成否认或正常；一般项目和医师署名未自行编造。常规入院记录不自动加手术计划或诊疗医嘱，除非院内模板或用户本次明确要求且有资料。

## 模板选材依据

2026-10-23核对，仅用于选择检查条目和区分适用场景，不用于把典型体征写成患者事实：

- [AAOS：髋关节骨坏死](https://www.orthoinfo.org/diseases--conditions/osteonecrosis-of-the-hip)：早期可有疼痛而活动度相对保留，进展后可出现僵硬及活动丧失，因此不能从病名固定推出同一组角度或Thomas征。
- [AAOS：髋骨关节炎](https://www.orthoinfo.org/diseases--conditions/osteoarthritis-of-the-hip/)：局部压痛、主动／被动活动及步态等条目；不把关节病的活动检查机械套用于急性骨折。
- [RCP：跌倒后四肢检查](https://www.rcp.ac.uk/improving-care/national-clinical-audits/falls-and-fragility-fracture-audit-programme-fffap/national-audit-of-inpatient-falls-naif/post-fall-medical-examination-a-guide-for-inpatient-settings/secondary-survey-extremities-bones-and-joints-in-all-four-limbs/)：外观、软组织、压痛及疑似骨折远端神经血运等；特定损伤和操作安全仍需逐例判断。
- [AAPM&R：腰椎管狭窄](https://now.aapmr.org/lumbar-stenosis/)：局部、活动、感觉、肌力、反射及相关特殊检查等选材；不能扩展为所有脊柱病种的统一操作要求。

以上没有验证所有骨科病种的模板。遇不熟悉或安全性依赖分期的诊断，按 [依据查证](sources.md#诊疗逻辑的依据) 检索适用的专业原文，并保持示例身份与实际患者事实分明。
