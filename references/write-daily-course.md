# 日常病程写法

用于本次查房时点和上次记录后的实际区间事件。整体结构见 [日常病程记录结构](document-types.md#日常病程记录)，按临床段落叙述，不把入院病史或前日查体直接复制为今日记录。

## 区分三类资料

- **可引用的背景**：入院诊断、已确认历史手术等必要事实，注明实际日期或历史性质。
- **本次观察**：本次症状、生命体征、实际专科查体、当次功能和最新检查。原文只说“未提供”就不能写“未做”；医生明确未查或未复查时可如实表述。
- **区间事件**：上次记录后实际发生的检查、会诊、措施、医嘱变更、响应、沟通及其时间，不能都当成本次查房当时发生。

“同前”或“稳定”仅在用户明确作出本次确认时按原粒度写，不能展开为未提供的一组正常体征。今日未提及昨日异常，不代表异常消失或恢复正常。

## 围绕本次变化成稿

1. **症状与实际查体**：写本次情况。比较昨日时，沿用明确的比较描述或可比的同项测量；没有基线就不写较前改善。不能仅因先治疗、后症状减轻就新增治疗有效的因果结论。
2. **新检查及分析**：标明报告日期、来源、关键值及单位。未提供新结果不写“复查正常”；引用旧报告标旧日期，不包装为今日复查。分析只用医生已给意见和本例已有证据。
3. **措施及效果、医嘱变化**：分开已实施、拟实施及仅下达未执行。效果和调整原因按实际描述；“继续原方案”可保留，但没有具体当前医嘱确认时，不自行列昨日药物为今日持续处方。
4. **后续安排与沟通**：只写医生已定计划和实际发生的告知，保留当前决策状态。未给时不补“已充分沟通、患者无异议”。

骨科按实际阶段选取已给的疼痛、伤口／敷料、引流、患肢血运神经、活动与负重等变化。未采集的项目留待补，不将所有可能项目机械设为必填。需要术后日数时按 [骨科提示](orthopedics.md) 的日期规则处理，手术不明确或多次手术指向不明时不猜。

## 当日资料不足或异常待核

只有昨日记录而无今日资料时，输出本次待填草稿或简短索取今日症状、实际查体、区间事件与医生安排；不能代写今日正常，也不能连续生成多日恢复过程。用户要求连写多天时，有哪天资料写哪天；其他日期保留待填，不把复制视为已观察。

本次已有明确症状而查体等缺失时先成稿，具体缺项放在相应位置。重要异常按[异常提醒](orthopedics.md#异常提醒)区分当前状态与历史事件，并核对提醒条件；“只要正文”时不把提醒伪装成已完成处置。

## 完成核对

每个当前体征有本次来源；历史资料带实际日期；改善或疗效有对应依据；手术／用药／会诊等状态正确；未提供资料与未做明确区分；计划、观察与沟通均有来源。不自动生成上级医师姓名、实际查房或意见，也不把日常病程替成术后首次病程。
