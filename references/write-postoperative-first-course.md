# 术后首次病程：普通三项与转入ICU四项

普通版已选定“手术简要经过、术后处理措施、术后注意观察事项”三项；术后转入重症监护病房（ICU）版使用下方四项。两者均采用通用、概括、规范的临床段落，以诊断、手术名称及同一病例上下文起草。已有实际资料纳入，其余时间、诊断、麻醉、人员、标本及出血量等字段仅在另有要求时生成。

明确要求完整术后首次病程（含完整结构及完整示例）时，采用[完整骨架](document-types.md#术后首次病程记录)；下方普通三项及ICU四项继续用于相应局部请求。

## 区分模板与实际记录

- **模拟／示例模板**：明确保持示例身份，可根据术式组织与之相符的一般手术顺序，供用户按实际情况修改。只选能代表该术式的主要环节，不默认具体手术入路、麻醉、植入物型号、固定方式、失血量、送检或引流事实，也不自动加“手术顺利、无并发症、生命体征平稳、安返病房”。
- **实际资料成稿**：简要经过只归纳本次已给步骤、术中所见及相关事件，处理措施区分已实施与拟行。仅有术式名称不足以推断实际入路、步骤、复位效果和手术结束情况；已有部分先写，关键未知按实际记录规则处理，不将上方模拟内容当成本例事实。

手术侧别和既定限制依本例输入；未给侧别的通用模板可用“患侧／患髋”等措辞。全髋与人工股骨头置换、内固定与关节置换等操作目的及主要环节应对应，不能只替换术式名称。转入ICU时使用下方专门栏目；手术记录和日常病程分别按当次要求处理。

## 普通版三项写法

### 手术简要经过

简述显露、病变或损伤处理、重建／固定／置换的主要环节及切口关闭等相关过程，采用完成步骤的临床叙述。模拟范例保持流程概括，不写成详细操作教程；实际记录按已给经过取舍。已知重要术中变化如实保留，不能用平稳范文覆盖异常。

### 术后处理措施

按病种及手术特点概括监测、疼痛管理、对症支持、感染及血栓等相关并发症预防、护理和康复原则。新增方向作为拟行安排，具体医嘱及实施状态依本例；不自动补药物、剂量、疗程、统一禁食时间或固定负重进度。活动、负重及防脱位措施结合手术入路、固定／假体情况及医师已定限制，不能统一套用。

### 术后注意观察事项

选择与本术式相关的意识与生命体征、切口渗血、疼痛肿胀、局部神经血运及相应并发症征象，写观察重点，不写成已经检查正常的结论。有引流时再写引流观察；未知是否留管时可用条件表述。观察计划与患者现有异常分开，已给异常及处置状态优先保留。

## 术后转入ICU：四项写法

本用户选择的顺序为“手术简要经过、术后处理措施、转入目的、注意观察事项”。只给诊断、术式及“术后转入ICU”，并明确要求模拟时，直接生成这四项通用范文；普通版继续使用三项，用户只选部分则仅写所选栏目。

手术简要经过沿用上方术式概括规则，可在段末保留用户已给的术后转入ICU事实。

术后处理措施兼顾重症监护与骨科围手术期管理，概括生命体征、氧合和出入量监测，按病情评估呼吸、循环、容量及内环境，安排疼痛管理、对症支持和适宜的并发症预防；患肢保护与活动按手术限制及病情允许程度表达。具体器官支持、药物及执行状态依本例输入。

转入目的写加强术后监护、评估重要脏器功能、及时识别和处理病情变化的管理目标。通用目的与本例收治原因分别表达：仅有转入ICU不代表已发生呼吸衰竭、休克、意识障碍或存在特定合并症，也不代表所有关节置换患者均需ICU；已有具体原因时如实纳入。实际记录须据真实原因组织，通用目的不替代未提供的收治依据。

注意观察事项结合全身变化与术区情况，兼顾意识、呼吸、循环、氧合、尿量及切口、患肢神经血运等变化，并选择适用的出血、感染、血栓栓塞及假体相关并发症征象。有引流或其他管路时再写相应观察，未知时使用条件表达。观察目标不写成患者已经出现的异常或已检查正常的结论。

## 输出与完成核对

默认交付所选版本的可复制临床正文，不附审查、资料采集清单或通用免责声明。普通版使用以下三项；ICU版按上节四项顺序，在处理措施后增加“转入目的”，末项标题为“注意观察事项”。用户只选部分时仅写所选项：

手术简要经过：

术后处理措施：

术后注意观察事项：

使用 [规范医学术语](writing-workflow.md#医学术语与临床表达)。模拟身份在本次语境或正文外简短说明，正文内不夹过程解释；用户要纯文本时不加写作块或代码围栏。具体临床建议按 [依据查证](sources.md#诊疗逻辑的依据) 核对适用一手来源，必要的来源放正文外。

完成标准：普通三项、ICU四项或用户指定项齐全；术式、部位及上下文一致；模拟流程与实际事实分明；没有擅加正常结果、无并发症或已执行医嘱；处理和观察不机械套用不适用的引流、活动及药物安排。既有完整文书与严格[]能力保留。

结构参考：[《病历书写基本规范》卫医政发〔2010〕11号政府卫生部门全文](https://eq.jiceng.zhengzhou.gov.cn/021011002/6447542.jhtml)，第二十二条（十八）；普通版三项是用户从其模板中选定的局部书写范围。当前写法承接用户在2026-10-23接受的模拟范文；具体全髋置换及髋部骨折选材曾核对 [AAOS全髋关节置换](https://www.orthoinfo.org/treatment/total-hip-replacement/)和[髋部骨折](https://www.orthoinfo.org/diseases--conditions/hip-fractures/)，不作为所有骨科术式的统一处理方案。

ICU分支源于用户在2026-10-23确认的四项结构及通用写作要求；参照[SCCM ICU收治、转出与分诊指南（2016）](https://www.sccm.org/clinical-resources/guidelines/guidelines/icu-admission%2C-discharge%2C-and-triage-guidelines)的适用框架，将监护目标与实际收治依据分开，不据术式推定ICU收治指征。此处未内置ICU收治阈值或器官支持方案。
