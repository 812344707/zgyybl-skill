# 写作路径

用于已明确的写作任务。学生入院稿的默认审查及两路径衔接见[技能入口](../SKILL.md#路径选择与衔接)；实际事实、示例及拟稿的边界统一见[事实准入](../SKILL.md#事实准入)。

## 确定书写范围

先确定书写范围，再按各段内容选择成稿方式，最后从下表读取对应文书指引。同一份草稿可以包含实际资料整理及已授权的分析／计划拟稿，各自保持事实来源和行为状态：

- **仅补[]**：直接执行[占位符规则](bracket-completion.md)，冻结括号外文字，不进入下方普通成稿。
- **通用拟稿**：根据已给诊断、手术或病情背景，按专门指引写通用、概括、规范的临床意见和拟行原则；缺少细节时提高概括程度，不以补材料清单代替正文。实际患者状态及已发生事件仍按已有资料整理。
- **示例／模拟**：保持示例身份，使用本次设定及明确引用的同病例背景。入院专科检查默认可按主诊断给可修改范文；其他文书允许的示范内容按各自指引选择。
- **实际资料整理、续写或润色**：执行下方实际资料步骤；只改所选段落，保留事实和原始数据，未知与冲突就地处理。
- **先列结构供标注**：仅交付所选标题、内容说明及空白“重点提醒”，不追加病例模拟。用户逐项确认、修改及参照学习的持久化按[迭代流程](reference-learning.md#反馈与完成核对)处理。

诊断模板已有明确诊断及必要部位即可开始；实际资料零散不要求重填固定表。只有会改变本次任务且无法从语境判断的信息才询问，不重复索取已有内容。一次写多份仅在同一患者、同次诊疗语境内共用事实和时间线。

“首次病程”通常指入院首次病程，术后首次病程另选对应行。用户只指定局部时仅写所选栏目；明确要求完整文书、完整结构或完整示例时，采用对应完整骨架，未内置骨架的文书按所给院内模板或[适用依据](sources.md)组织。实际资料整理本身不触发全文；完整请求仅改变栏目范围，事实仍按本次成稿方式及专门指引处理。院内标题和编号按用户格式保留。

## 实际资料整理

以下步骤用于实际资料部分；同一答复中的通用拟稿、示例及结构整理按上方对应分支处理。

1. **对齐资料与时点**：按患者整理病例代号、已给年龄性别、事件及记录时间、病史查体、报告来源、医师结论和实际措施。区分患者自述、外院／既往资料、本次观察、计划、执行及效果；实际缺失和冲突仅影响相关表述。
2. **组织所选栏目**：在所需文书范围内先写已知部分，再放置必要且具体的待补充或待核实标记。未给整个类别时合并标记，不将每一种骨科检查都列成必填。骨科资料按[骨科提示](orthopedics.md)选择；范文中的正常结果、日期和签名不随模板复制。
3. **保留判断与行为状态**：围绕已给诊断组织现有依据，保留其确定程度；未经授权的新鉴别、处置与个体用药不冒充医师已定决定。实际发言、沟通和医嘱执行均按本次来源记录。已授权的分析或计划拟稿按对应文书指引写入草稿栏目。
4. **核对后交付**：核对患者归属、部位侧别、事件顺序、数值单位、诊断确定程度及拟行／已执行状态。多份记录按各自时点衔接，实际演变可保留差异。阶段、转科和出院摘要涉及待回结果或已知治疗变更时，按[交接核对](source-materials.md#待回结果与交接)落在所选栏目内。内部核对不自动增加审查报告；影响本次记录的遗漏或不足按[尾部提醒](#遗漏与不足提醒)处理。

## 医学术语与临床表达

适用于实际病历、通用拟稿及诊断驱动示例；冻结原文时仅作用于获准新写的部分。

- **部位和动作**：明确解剖部位及侧别，区分屈伸、内收外展、内外旋、主动被动活动、感觉、运动和血运。
- **查体术语**：按已表达的实际含义规范压痛、叩击痛、肿胀、畸形、活动度、感觉、肌力及动脉搏动等；口语整理不扩写未给的神经分布、肌力分级或特殊试验。
- **结果与状态**：未查、受限未查、阴性和未见异常分别表达；定性描述不改成未测量的时间、角度、评分或具体正常值。已有汇总描述保持相同粒度。
- **名称及缩写**：病名、术式、药物通用名和剂型使用规范名称；含义明确的英文缩写首次附中文全称，常用人名试验可附原文。含义不明先核对。
- **时间及数字单位**：日期时间均已知时采用24小时制YYYY-MM-DD HH:MM；只有日期保留日期。新写数字与单位之间留空格，如170 cm、120/80 mmHg；保留原值、范围、精度、单位和含义，格式化不补造时刻或数值。
- **临床语体**：用简洁、客观的临床句式，正文不夹生成过程说明、审查清单或文学修饰。术语整理前后侧别、阴阳性、数值和确定程度一致；示范性结果仅用于明确示例。

## 常规输出

各文书正文默认按目录所指的范围、标题及顺序输出；专门指引决定正文组织，尾部提醒统一按下节处理。仅选局部不扩展全文，完整记录能力保留。

通用拟稿及示例直接交付可独立复制的临床正文，不以补材料回执、评分、审查报告或通用免责声明替代正文。示例身份和必要来源放正文外；尾部提醒只处理本次实质问题。

实际病历成稿默认将已知事实和必要缺项按所选栏目组织成临床段落，不以资料表代替病历正文；单纯整理报告或用户明确要求表格时按本次格式交付。医师核签仅在本次完整结构需要时留待核签，不生成签名。必要缺项在相应正文位置标明，再按下节将重要问题合并为简短尾部提醒；未授权的新临床判断或个体处置与正文事实分开，不借提醒生成医嘱。

用户要纯文本时不用写作块、代码围栏或表格；需要的尾部提醒也使用纯文本并与正文分隔。未指定纯文本时可用可复制写作块，保留所需标题及编号，提醒放在写作块外。来源及必要处理说明先于尾部提醒放在正文外；仅补[]始终执行其冻结及纯文本约定。不声称完成正式质控、签署或归档。

## 遗漏与不足提醒

每次普通写作完成后，核对本次所选范围的资料和成稿。发现影响记录完整性、事实一致性或判断依据的实质问题时，在整份答复尾部另列“遗漏与不足提醒（非病历正文）”；没有实质问题时不强凑提醒，也不宣称资料齐全或正式质控合格。

- **提醒什么**：明确未填的必要项目、侧别／时间等冲突、记录结论缺少已给支持依据、待回结果或已知安排未衔接、会造成事实误读的表达。只限本次请求涉及的问题；材料未提供只说“未提供／需补充或核实”，不等同于未检查、未执行或整份病历不存在。
- **怎样提醒**：优先合并为1—3项，说明“具体项目＋需补充或核对的方向”，重要问题较多时可增加；同一问题只提醒一次。正文已有占位时可概括其重要缺口及下一步，不逐项抄回占位符，不重列整套资料清单；提醒不替代可写正文，也不代填未知事实、作新诊断或下医嘱。
- **按模式取舍**：通用拟稿、示例及仅列结构不以未设定的患者细节强凑不足；发现已给背景冲突、超出依据的断言或所选实际栏目仍有重要资料缺口时才提醒。局部请求不因提醒扩展其他章节；已授权的通用分析继续写入所选正文。
- **混合写作**：实际资料与授权拟稿并存时，分别核对。实际部分已标出的、影响本次事实描述、分析判断或交接安排的重要缺项，应合并进入尾部提醒；不能因另一段是通用计划或整份答复标为草稿而省略。通用部分仍按其适用范围取舍，不把未设定的个体细节列成采集清单。
- **与正文分开**：临床正文可单独复制；有写作块时提醒置于块外，纯文本时用空行和上述纯文本标题分隔。必要来源或其他处理说明放在提醒之前，已单列的问题不再次重复。
- **明确输出限制**：“只写某栏、不增加其他栏目”限制正文范围，仍按上述条件另列提醒。本次明确只要病历正文、不附说明时，必要缺项仍在正文相应位置标明，不自动加普通尾注；仅补[]继续专门冻结与纯文本分支，不追加。只有文书或转录文字之间的差异、未提供当前患者身份或治疗侧别安全情境时，作为资料冲突在尾部提醒核对，不由文字差异自行推定紧急场景。当前未处理的重大异常或患者／治疗侧别安全问题仍按[异常提醒](orthopedics.md#异常提醒)的条件及时提示，不等到普通尾注才处理，同一安全问题不重复提醒。
