# 写作路径

用于已明确的写作任务。学生入院稿的默认审查及两路径衔接见[技能入口](../SKILL.md#路径选择与衔接)；实际事实、示例及拟稿的边界统一见[事实准入](../SKILL.md#事实准入)。

## 确定书写范围

先确定书写范围，再选择成稿方式，最后从下表读取对应文书指引：

- **仅补[]**：直接执行[占位符规则](bracket-completion.md)，冻结括号外文字，不进入下方普通成稿。
- **通用拟稿**：根据已给诊断、手术或病情背景，按专门指引写通用、概括、规范的临床意见和拟行原则；缺少细节时提高概括程度，不以补材料清单代替正文。实际患者状态及已发生事件仍按已有资料整理。
- **示例／模拟**：保持示例身份，使用本次设定及明确引用的同病例背景。入院专科检查默认可按主诊断给可修改范文；其他文书允许的示范内容按各自指引选择。
- **实际资料整理、续写或润色**：执行下方实际资料步骤；只改所选段落，保留事实和原始数据，未知与冲突就地处理。
- **先列结构供标注**：仅交付所选标题、内容说明及空白“重点提醒”，不追加病例模拟。用户逐项确认、修改及参照学习的持久化按[迭代流程](reference-learning.md#反馈与完成核对)处理。

诊断模板已有明确诊断及必要部位即可开始；实际资料零散不要求重填固定表。只有会改变本次任务且无法从语境判断的信息才询问，不重复索取已有内容。一次写多份仅在同一患者、同次诊疗语境内共用事实和时间线。

“首次病程”通常指入院首次病程，术后首次病程另选对应行。用户只指定局部时仅写所选栏目；明确要求完整文书、完整结构或完整示例时，采用对应完整骨架，未内置骨架的文书按所给院内模板或[适用依据](sources.md)组织。实际资料整理本身不触发全文；完整请求仅改变栏目范围，事实仍按本次成稿方式及专门指引处理。院内标题和编号按用户格式保留。

## 实际资料整理

以下步骤用于实际记录成稿；已授权的通用拟稿、示例及结构整理先按上方对应分支处理。

1. **对齐资料与时点**：按患者整理病例代号、已给年龄性别、事件及记录时间、病史查体、报告来源、医师结论和实际措施。区分患者自述、外院／既往资料、本次观察、计划、执行及效果；实际缺失和冲突仅影响相关表述。
2. **组织所选栏目**：在所需文书范围内先写已知部分，再放置必要且具体的待补充或待核实标记。未给整个类别时合并标记，不将每一种骨科检查都列成必填。骨科资料按[骨科提示](orthopedics.md)选择；范文中的正常结果、日期和签名不随模板复制。
3. **保留判断与行为状态**：围绕已给诊断组织现有依据，保留其确定程度；未经授权的新鉴别、处置与个体用药不冒充医师已定决定。实际发言、沟通和医嘱执行均按本次来源记录。已授权的分析或计划拟稿按对应文书指引写入草稿栏目。
4. **核对后交付**：核对患者归属、部位侧别、事件顺序、数值单位、诊断确定程度及拟行／已执行状态。多份记录按各自时点衔接，实际演变可保留差异。阶段、转科和出院摘要涉及待回结果或已知治疗变更时，按[交接核对](source-materials.md#待回结果与交接)落在所选栏目内。内部核对不自动增加审查报告。

## 医学术语与临床表达

适用于实际病历、通用拟稿及诊断驱动示例；冻结原文时仅作用于获准新写的部分。

- **部位和动作**：明确解剖部位及侧别，区分屈伸、内收外展、内外旋、主动被动活动、感觉、运动和血运。
- **查体术语**：按已表达的实际含义规范压痛、叩击痛、肿胀、畸形、活动度、感觉、肌力及动脉搏动等；口语整理不扩写未给的神经分布、肌力分级或特殊试验。
- **结果与状态**：未查、受限未查、阴性和未见异常分别表达；定性描述不改成未测量的时间、角度、评分或具体正常值。已有汇总描述保持相同粒度。
- **名称及缩写**：病名、术式、药物通用名和剂型使用规范名称；含义明确的英文缩写首次附中文全称，常用人名试验可附原文。含义不明先核对。
- **时间及数字单位**：日期时间均已知时采用24小时制YYYY-MM-DD HH:MM；只有日期保留日期。新写数字与单位之间留空格，如170 cm、120/80 mmHg；保留原值、范围、精度、单位和含义，格式化不补造时刻或数值。
- **临床语体**：用简洁、客观的临床句式，正文不夹生成过程说明、审查清单或文学修饰。术语整理前后侧别、阴阳性、数值和确定程度一致；示范性结果仅用于明确示例。

## 常规输出

各文书默认按目录所指的范围、标题及顺序输出；专门指引优先于下方实际成稿约定。仅选局部不扩展全文，完整记录能力保留。

通用拟稿及示例直接交付可独立复制的临床正文，不附补材料回执、评分、审查报告或通用免责声明。示例身份和必要来源放正文外；语境已明确且用户只要正文时仅给正文。

实际病历成稿默认将已知事实和必要缺项按所选栏目组织成临床段落，不以资料表代替病历正文；单纯整理报告或用户明确要求表格时按本次格式交付。医师核签仅在本次完整结构需要时留待核签，不生成签名。正文外只列确需处理的缺失或冲突，正文已清楚标记的项目不重复列清单；未授权的新临床建议仅在用户要求分析或存在需说明的实质问题时单列。

用户要纯文本时不用写作块、代码围栏、表格或前后说明；未指定纯文本时可用可复制写作块，保留所需标题及编号。来源链接、处理说明和审查意见放可复制正文外；仅补[]始终执行其冻结及纯文本约定。不声称完成正式质控、签署或归档。
